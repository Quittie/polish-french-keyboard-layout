# Polish Programmer + French Accents

[Quittie](https://github.com/Quittie) · [MIT License](LICENSE)

A Windows keyboard layout based on **Polish (Programmers)**. Polish AltGr letters remain available, and dead-key sequences add French accents and punctuation. No background app is needed.

Tested on Windows 11 Home 26H2 (x64).

Examples: `\a` → à, `/e` → é, `;c` → ç, `;e` → œ, `;<` → «, `;>` → », `;'` → ’, `;-` → –. `;=` inserts a non-breaking space. See [KEYMAP.txt](KEYMAP.txt) for all mappings.

## Files

- `POL_FR_source.klc` — the editable source file for Microsoft Keyboard Layout Creator (MSKLC) 1.4. Keep its UTF-16 encoding when downloading or editing it.
- `POL_FR_x64.dll` — a compiled copy for 64-bit Windows. It is **not an installer**.
- `KEYMAP.txt` — plain-text shortcut reference.
- `LICENSE` — MIT license.

## Install on another Windows PC

1. Download and extract this repository.
2. Install [Microsoft Keyboard Layout Creator 1.4](https://www.microsoft.com/en-us/download/details.aspx?id=102134).
3. In MSKLC, choose **File → Load Source File…** and open `POL_FR_source.klc`.
4. Choose **Project → Build DLL and Setup Package**. Run `setup.exe` from the generated folder and approve the Windows administrator prompt.
5. Select **Polski programisty + francuskie akcenty - Custom** with **Win + Space**. If it does not appear immediately, sign out or restart Windows.

The `.klc` file is the source to keep for future changes. The DLL is provided for reference; install with the package generated by MSKLC.
